How to reduce a photo to 50 KB, or any size limit

Online forms want photos under 20, 50, 100 or 250 KB. Here is what makes a photo big, and how to bring it under any limit while keeping it as clear as possible.

By llemonai · 15 November 2026 · 6 min read

Online forms for exams, jobs, scholarships and government services often accept photos only under a size limit: 20 KB, 50 KB, 100 KB or 250 KB. A phone photo is usually several megabytes. This guide explains what actually makes a photo big, and how to bring it under any limit while keeping it as clear as possible.

KB and pixels are not the same thing

Two different numbers describe a photo, and forms often ask about both:

  • Pixel size, such as 4000 × 3000 or 630 × 810: how many dots make up the picture.
  • File size, such as 2.4 MB or 48 KB: how much space the file takes. 1 MB is about 1000 KB.

A JPEG photo's file size depends on its pixel size and on its quality setting. You can make a file much smaller by lowering the JPEG quality a little, often with no difference you can see on screen. Only when the limit is very small do you also need fewer pixels.

Read the form's rules first. If it also asks for a pixel size (for example 200 × 230), set that first, then bring the file under the KB limit. If it asks for a format, use JPG unless it says otherwise.

The quick way: save with a maximum file size

  3. Check the Before / After table: it shows the pixels, print size, DPI and estimated file size before you apply.
  4. Click Apply size & resolution, then save with a maximum file size as above.

What about DPI?

DPI (dots per inch) only says how large a photo prints; it doesn't change the file size on its own. If a form asks for "300 DPI", set the DPI in Image size & resolution with Resample off: the pixels stay exactly the same and only the print size changes. The app writes the DPI into the saved JPG.

Tips for very small limits (20–50 KB)

  • Crop first. Cut away background you don't need; fewer pixels of empty wall means more of the file goes to your face or signature.
  • Start smaller for 20 KB: choose Small (800 px) or the pixel size the form gives, then save with the limit.
  • Plain backgrounds compress better. A busy background takes more KB than a plain one at the same quality.
  • Never enlarge a small photo to meet a minimum pixel size if you can avoid it; it adds pixels but not detail.

Common problems

  • The form says the file is too big, but it's under the limit: some forms count 1 KB as 1024 bytes. Save a few KB under the limit.
  • The form rejects HEIC photos from an iPhone: open the photo in the app and save as JPG. HEIC opens on Android and Mac; on Windows, save it as JPEG on the phone first.
  • The photo looks blurry after shrinking: the limit is very small for its pixel size. Crop tighter or set the exact pixel size the form asks for, then save again.
  • You need a passport photo for Passport Seva: use Passport mode's Save for online form instead; see how to make a passport photo at home.

Quick checklist

  • Check the form: KB limit, pixel size, format.
  • Set pixels or cm in Image size & resolution if the form asks.
  • Save → JPG → Maximum file size (KB), a little under the limit.
  • Check the final size before uploading.
